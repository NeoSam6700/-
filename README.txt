# HOOKAH NEON

Мобильный PWA-трекер кальянных смен.

## Запуск
Разместите файлы на HTTPS-хостинге (например, GitHub Pages). Для локального просмотра можно открыть index.html.

## Данные
Записи, список позиций и тарифы хранятся в localStorage браузера. В разделе «Настройки» доступны экспорт и импорт JSON-резервной копии. Перед крупными изменениями рекомендуется сделать экспорт.

## Позиции и тарифы
В настройках можно добавлять позиции, менять их названия и тарифы, отключать и возвращать позиции. Отключение не удаляет старые записи. Тариф фиксируется в каждой смене, поэтому изменение цены влияет только на новые смены.

## Известные тарифы по умолчанию
- Классика — 200 ₽
- Двойной — 200 ₽
- Mirai — 350 ₽
- Electric Matcha — 320 ₽

Остальные тарифы по умолчанию равны 0 и настраиваются пользователем.
