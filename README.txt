# HOOKAH NEON

Мобильный PWA-трекер кальянных смен.

## Запуск
Откройте `index.html` в браузере для локального просмотра. Для установки как PWA и офлайн-кеша разместите файлы на HTTPS-хостинге (например, GitHub Pages).

## Данные
Записи и тарифы хранятся в localStorage браузера. В разделе «Настройки» доступны экспорт и импорт JSON-резервной копии.

## Тарифы
Предзаполнены только ранее известные тарифы:
- Классика — 200 ₽
- Двойной — 200 ₽
- Mirai — 350 ₽
- Electric Matcha — 320 ₽

Остальные тарифы по умолчанию равны 0 и настраиваются в разделе «Настройки → Тарифы».
